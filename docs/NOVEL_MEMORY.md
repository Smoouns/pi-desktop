## 数据与权限

- CANON：作者控制的设定、明确映射的正典正文。
- DERIVED：配置指定的当前状态/连续性账本，以及有效人工验收记录绑定的候选正文。已验收未晋升正文必须显示“已验收，未晋升”。
- 原始 Continuity Proposal 不因正文验收而自动成为事实来源；仅用户确认写入账本或当前状态的内容进入本版索引。
- SUMMARY / SCRATCH：保留设计，不索引未审核摘要、普通笔记、会话或未来规划。已确认设定也不代表角色已经知情；命中保留章节及标题，未来节点单独标记。
- 记忆条目直接引用源文，记录项目、路径、完整源文件 SHA-256、行范围、标题、来源类型、权威性、时间属性、观察时间及索引器版本。检索分数不是事实置信度；不伪造原作者或原始创建时间。

首版索引在每次查询时从当前文件重建，无持久内容数据库。目录扫描跳过符号链接与项目管理/归档目录，路径限定在当前项目。正文与章节卡的指纹必须同时匹配人工验收记录；对应章节卡确认失效后，不再检索该候选正文。

文件修改、删除、世界观回滚、验收失效、项目配置变化均反映在下次查询；旧记忆 ID 再次读取时必须通过最新快照验证，否则要求重新搜索。时间视角筛选先于排名，不使用未来章节填补较早章节的查询。无法机械判定的角色知情边界仍由 Agent 依据原文判断。

## 用户与 Agent 入口

上下文工作台增加记忆检索，显示片段、来源、理由与估算 token，可打开源文或手动加入本次请求。注入只带版本绑定的记忆引用；模型用 `read_story_memory` 读取。所有职能提供 `search_story_memory` / `read_story_memory` 只读工具，不增加自动记忆写入权。

## 当前限制

- 这是确定性关键词检索，不是语义事实抽取或自动冲突裁决；同义表达可能漏召回。
- “未来节点”主要按标题识别；角色知情、历史版本和含混时间仍需对照原文，不能用筛选代替语义审阅。
- 单条来源片段最多 8,000 字；超长单段/围栏会明确警告并跳过，需直接查看源文件。扫描及查询总量另有预算。
- 索引可重建，但不承诺多进程同时编辑时的原子快照；最终修改 Canon 仍走现有用户确认和指纹核验流程。
