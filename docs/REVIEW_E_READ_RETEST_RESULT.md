## 已确认的根因与修复

`get_context_budget`、检查点等诊断结果不进入 Observation 存储。它们在工具返回时已扣工具结果字节额度，但第一次投影到下一次模型上下文时，又被当作历史结果扣一次。定向红灯将一条结果复现为 **2,989 → 5,978 字节**；不只是诊断结果偏大。

生产扩展 v25 增加最多 512 条、仅当前 run 持有的内容哈希回执，键包含工具名称、调用 ID 和实际返回内容。成功计入额度后才登记；再次投影完全相同的结果不重复扣本轮工具输出额度。真实的新调用仍计入额度，历史 / 外来 / 内容变化结果不能借持久化 metadata 绕过预算。

- **64 KiB 工具结果额度不变**；最终模型输入估算仍包含这些文本。
- Observation 来源校验走原路径，未跳过来源新鲜度、读取交付或检查点校验。
- 回执不写入消息或磁盘，换会话 / run 后不继承。
- 不修改全局 Pi / 代理配置、真实小说或上游输出参数。
