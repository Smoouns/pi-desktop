3. 固定 SDK 返回 `Tool list_dir not found`，测试外围记录未启用工具尝试并触发 `tool_permission`。**成功工具执行为 0**，Canonical / 人工验收 sentinel 及测试来源 v1 字节不变。
4. SDK 随后的循环入口被取消：生产计量为 2 个普通 provider 入口，其中 1 个成功、1 个 aborted；只有 **1 次 Fetch / 1 次 broker 派发 / 1 个完整响应**。不能把 2 个入口写成 2 次收费请求；也不能把只读恢复工具里的 `httpReceived=0`（该字段统计本机合成服务器）误解为未发送真实请求。
